# Bug reports

Two worked examples filed against the **bundled demo app** (`demo/`), so anyone who
clones this repository can reproduce them. They are real observations about that app,
not illustrations.

Reports from client work are not published here: the defects, the systems and the
client's identity are covered by confidentiality. That work is walkable in an
interview, with the details removed.

Use `TEMPLATE.md` for the shape: title, severity against frequency × impact, environment,
preconditions, numbered reproduction, expected vs actual, evidence, and the one line that
makes a report useful — what the reporter thinks is happening, marked as a hypothesis.
